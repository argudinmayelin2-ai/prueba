# Calculadora

Calculadora web adaptable a móviles, hecha con HTML, CSS y JavaScript sin dependencias.

## Ejecutar en localhost

Con Python instalado:

```bash
python -m http.server 8000
```

Abre [http://localhost:8000](http://localhost:8000).

También puedes abrir `index.html` directamente en el navegador.

## Uso

- Operaciones: suma, resta, multiplicación y división.
- Porcentaje, cambio de signo, decimales y borrado.
- Teclado: `0–9`, `+`, `-`, `*`, `/`, `%`, `Enter`, `Escape` y `Backspace`.
